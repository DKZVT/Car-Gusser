    玩 法

    猜出这台性能车，共 10 次机会。每次猜完，8 项属性都会上色：

    完全一致 接近 不对

    年款、气缸、马力这三项还会带 ↑ / ↓，指示答案比你的猜测更大（更晚）还是更小（更早）。

    年款生产年份，相差 ±5 年内算接近
    国别原产国，同一大区算接近（欧洲 / 亚洲 / 北美）
    气缸气缸数，相差 ±2 算接近；转子发动机记转子数；纯电车为 0
    车门数只数乘员门，不把后备箱门/尾门算进去（3 门掀背记 2，5 门掀背/SUV/旅行车记 4）；没有乘员门的开放式车记 0，单体壳赛车只能掀开车顶钻进去的记 1（如 Solus GT、X-Bow GT-XR）
    车种轿跑 / 跑车 / 超级跑车 / 轿车 / 掀背 / 敞篷 / 旅行车 / SUV / 皮卡（门数另有单独一栏，车种不再重复写"双门"）
    驱动前驱 / 后驱 / 四驱，必须完全一致
    进气自然吸气 / 涡轮增压 / 双涡轮 / 多涡轮（四涡轮以上，如布加迪 W16）/ 机械增压 / 机械+涡轮（双增压，如 Delta S4、沃尔沃 T8）/ 电动
    马力曲轴马力，相差 ±50 匹内算接近
